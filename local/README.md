# hypescript — עורך אוטומטי לסרטוני שיעורים בעברית

כלי CLI ב-Python שמקבל **וידאו מלא (או כמה קבצים)** ו**טקסט של מה שצריך להישאר**,
ומחזיר **סרטון שמכיל בדיוק את הטקסט הזה — מדויק, בלי נשימות ובלי שתיקות** — יחד עם
כתוביות עברית מסונכרנות.

הכל בכלים חינמיים ו-open source. אפשר לעבוד ב**ענן** (מהיר, מדויק, לא מעמיס על המחשב —
ברירת המחדל) או **מקומית** (פרטי לחלוטין, בלי שהאודיו יוצא מהמחשב).

---

## מה הכלי עושה

```
וידאו(ים)  ──▶  תמלול word-level  ──▶  חיתוך לפי סקריפט  ──▶  הסרת נשימות/שתיקות
           (ענן / מקומי)          (משאיר רק מה שבטקסט)      (רווחים > סף נחתכים)
                                                                     │
        סרטון ערוך (mp4) + כתוביות SRT + לוג חיתוכים  ◀──  הרכבה מחדש ב-FFmpeg
```

1. **תמלול** — WhisperX/Whisper בענן או faster-whisper מקומית, עם חותמות זמן ברמת המילה.
2. **חיתוך לפי סקריפט** (הלב של הכלי) — יישור עמיד (fuzzy) בין הטקסט שלך לתמלול; נשמר רק
   מה שתואם לטקסט, וכל השאר (חזרות, גמגומים, קטעים לא-רלוונטיים) נחתך.
3. **הסרת נשימות, שתיקות ומהססים** — כל רווח בין מילים ארוך מסף הדוק (ברירת מחדל 0.14 שנ')
   נחתך בעמק השקט שנמדד בגל, עם ריפוד קצר (0.025 שנ') בכל צד. עם `--remove-fillers` גם מילות-מהסס וגמגומים
   (אה/אמ/המ) נחתכים אוטומטית, גם כשהפאוזה סביבם קצרה.
4. **כתוביות** — SRT עברית מסונכרן לציר-הזמן *הערוך*, עם טיפול RTL נכון (UTF-8 + סימון
   כיווניות U+200F). אופציה לצרוב את הכתוביות בווידאו.
5. **אינטרו/אאוטרו** — צירוף פתיח/סיומת קבועים (תמונה או וידאו) בהתחלה/בסוף.

## דרישות מוקדמות

* **Python 3.9+**
* **FFmpeg + FFprobe** ב-PATH (תלות חיצונית, לא מותקנת דרך pip)
* למצב ענן: **מפתח API** (למשל Groq — יש free-tier נדיב)

### התקנת FFmpeg על Windows

הדרך הקלה ביותר — עם winget (מובנה ב-Windows 11):

```powershell
winget install --id Gyan.FFmpeg -e
```

או עם Chocolatey:

```powershell
choco install ffmpeg-full
```

**חשוב:** אחרי ההתקנה סגור ופתח מחדש את הטרמינל, וּודא שזה עובד:

```powershell
ffmpeg -version
ffprobe -version
```

(אם winget לא זמין — הורד build מ-<https://www.gyan.dev/ffmpeg/builds/>, חלץ, והוסף את
תיקיית `bin` ל-PATH של המשתמש.)

## מצב ענן (דרך שורת הפקודה)

### 1. השג מפתח (Groq, חינם)

היכנס ל-<https://console.groq.com/keys>, צור מפתח, והגדר אותו כמשתנה סביבה:

```powershell
$env:GROQ_API_KEY = "gsk_xxxxxxxxxxxxxxxxxxxx"
```

(כדי שיישמר בין הפעלות אפשר להעתיק את `.env.example` ל-`.env` ולמלא שם את המפתח —
הכלי טוען אותו אוטומטית מהתיקייה הנוכחית.)

Groq מריץ `whisper-large-v3` — הכי מדויק לעברית — והוא מהיר מאוד. אפשר גם OpenAI עם
`--cloud-provider openai` ו-`OPENAI_API_KEY`, או `--cloud-provider elevenlabs`
ו-`ELEVENLABS_API_KEY` (מודל ברירת מחדל: `scribe_v2`).

### 2. הרצה — התרחיש המרכזי

```bash
python -m hypescript שיעור.mp4 --script טקסט_נקי.txt -o שיעור_ערוך.mp4
```

זהו. תקבל:
* `שיעור_ערוך.mp4` — הווידאו הסופי (רק מה שבטקסט, בלי נשימות).
* `שיעור.srt` — כתוביות מסונכרנות.
* `שיעור_transcript.txt` — **הטקסט הסופי שנשאר בסרטון**, לקריאה והגהה מהירה.
* `שיעור_cuts.json` — לוג מדויק של כל מה שהוסר (timestamps).

> טיפ: פתח את `_transcript.txt` אחרי `--dry-run` כדי לוודא שהיישור תפס נכון —
> לפני שמשקיעים זמן ברינדור.

### כמה קבצים לקלט אחד

```bash
python -m hypescript חלק1.mp4 חלק2.mp4 חלק3.mp4 --script טקסט_נקי.txt -o מלא.mp4
```

הקבצים משורשרים לציר-זמן אחד, ואז הסקריפט חל על הכל.

## מצב מקומי (פרטי לחלוטין)

```bash
python -m hypescript שיעור.mp4 --engine local --model large-v3 --script טקסט_נקי.txt
```

* המחשב שלך (Intel Core Ultra, בלי GPU של NVIDIA) ירוץ על ה-**CPU** עם `int8` — זה
  תקין ומהיר-מספיק ל-5–10 דקות. `faster-whisper` לא משתמש ב-Arc/NPU, אבל דווקא בשביל
  המשימה הזאת CPU נותן את ה-word-timestamps הכי אמינים.
* `--model medium` = מהיר יותר, פחות מדויק. `--model large-v3` = הכי מדויק בעברית, איטי יותר.

## דוגמאות נוספות

```bash
# סקריפט + הסרת מהססים/גמגומים (התרחיש המלא):
python -m hypescript שיעור.mp4 --script טקסט.txt --remove-fillers

# רק הסרת נשימות + מהססים + כתוביות, בלי סקריפט (משאיר את כל התוכן):
python -m hypescript שיעור.mp4 --remove-fillers

# כתוביות צרובות בווידאו:
python -m hypescript שיעור.mp4 --script טקסט.txt --burn-subs --font "Arial"

# עם פתיח וסיומת:
python -m hypescript שיעור.mp4 --script טקסט.txt --intro פתיח.png --intro-duration 5 --outro סיום.mp4

# בדיקה מהירה בלי לרנדר וידאו — רק תמלול, SRT ולוג החיתוכים:
python -m hypescript שיעור.mp4 --script טקסט.txt --dry-run

# חיתוך אגרסיבי יותר של פאוזות (סף נמוך יותר):
python -m hypescript שיעור.mp4 --script טקסט.txt --silence-threshold 0.25
```

## כל הפרמטרים וכוונון

### קלט/פלט
| פרמטר | ברירת מחדל | הסבר |
|---|---|---|
| `input` | (חובה) | קובץ וידאו אחד או יותר |
| `-o, --output` | `<שם>_edited.mp4` | נתיב פלט הווידאו |
| `--srt-output` | `<שם>.srt` | נתיב קובץ הכתוביות |
| `--log-output` | `<שם>_cuts.json` | נתיב לוג החיתוכים |

### מנוע תמלול
| פרמטר | ברירת מחדל | הסבר |
|---|---|---|
| `--engine` | `cloud` | `cloud` (API) או `local` (faster-whisper) |
| `--model` | `whisper-large-v3` / `medium` | שם מודל (ענן) או גודל/נתיב (מקומי) |
| `--language` | `he` | שפה נכפית |
| `--device` | `auto` | מקומי: `auto`/`cpu`/`cuda` |
| `--compute-type` | `auto` | מקומי: `int8`/`float16`/`float32` |
| `--no-vad` | כבוי | מקומי: כיבוי סינון VAD (**לא מומלץ** — VAD מונע "מילות רפאים" בשתיקות) |

### ענן
| פרמטר | ברירת מחדל | הסבר |
|---|---|---|
| `--cloud-provider` | `groq` | `groq`/`openai`/`custom`/`elevenlabs` |
| `--cloud-base-url` | — | עקיפת כתובת ה-API (ל-`custom`) |
| `--api-key` | — | מפתח (או משתנה סביבה `GROQ_API_KEY`/`OPENAI_API_KEY`/`HYPESCRIPT_API_KEY`) |
| `--cloud-chunk-sec` | `1200` | פיצול אוטומטי של אודיו ארוך מזה (שנ') לפני העלאה, כדי לא לחרוג ממגבלת הגודל |

### עריכה
| פרמטר | ברירת מחדל | הסבר וכוונון |
|---|---|---|
| `--script` | — | קובץ טקסט של מה שצריך להישאר. **זה מפעיל את החיתוך-לפי-סקריפט.** |
| `--remove-fillers` | כבוי | הסרת מילות-מהסס וגמגומים (אה, אמ, המ...) אוטומטית, עם או בלי סקריפט |
| `--fillers` | ברירת מחדל | רשימת מהססים מותאמת מופרדת בפסיקים, למשל `"אה,אמ,יעני,כאילו"` |
| `--silence-threshold` | `0.14` | רווח (שנ') שמעליו פאוזה נחתכת. 0.14 = קצב פרסומי הדוק; ערך גבוה יותר משאיר יותר נשימה טבעית. |
| `--padding` | `0.025` | כמה שנ' להשאיר בכל צד של חיתוך. חותמות המילים מגינות על ההברות והגל ממקם את החיתוך בתוך העמק השקט. |
| `--no-silence-removal` | כבוי | אל תסיר שתיקות (למשל אם רק רוצים כתוביות) |

### כתוביות
| פרמטר | ברירת מחדל | הסבר |
|---|---|---|
| `--max-chars` | `42` | מקסימום תווים בשורה. **קטן יותר = שורות קצרות יותר**. |
| `--max-lines` | `2` | מקסימום שורות בכתובית |
| `--burn-subs` | כבוי | צריבת הכתוביות בווידאו (דרך libass) |
| `--no-srt` | כבוי | אל תכתוב קובץ SRT נפרד |
| `--font` | `Arial` | גופן לצריבה (חייב לתמוך בעברית) |
| `--font-size` | — | גודל גופן לצריבה |

### אינטרו/אאוטרו וכללי
| פרמטר | ברירת מחדל | הסבר |
|---|---|---|
| `--intro` / `--outro` | — | קובץ פתיח/סיומת (תמונה או וידאו) |
| `--intro-duration` / `--outro-duration` | `4.0` | משך (שנ') כשהפתיח/סיומת הם תמונה |
| `--dry-run` | כבוי | תמלול + חישוב חיתוכים + SRT + לוג, בלי רינדור וידאו |
| `--crf` | `20` | איכות וידאו (18–23 טיפוסי; נמוך=איכותי יותר) |
| `--preset` | `medium` | preset של x264 (איכות מול מהירות) |
| `-v, --verbose` | כבוי | פלט מפורט לניפוי |

## טיפים לכוונון תוצאה טובה

* **הסקריפט לא חייב להיות מדויק מילה-במילה** — היישור עמיד לשגיאות תמלול ולניקוד/פיסוק.
  אבל הוא כן צריך להיות **באותו סדר** של הדיבור ובאותה שפה.
* אם נחתך יותר מדי (משפטים נבלעים) — נסה מודל תמלול גדול יותר (`--model large-v3`),
  או בדוק את `<שם>_cuts.json` לראות מה בדיוק הוסר.
* אם נשארות נשימות — הורד מעט את `--silence-threshold` (למשל ל-0.18).
* אם החיתוכים נשמעים חדים — העלה מעט את `--padding` (למשל ל-0.15).
* **תמיד כדאי להריץ `--dry-run` קודם** — זה מהיר, ומראה לך בלוג בדיוק מה ייחתך לפני
  שמשקיעים זמן ברינדור.

## איך זה עובד (למתעניינים)

* **דיוק החיתוך:** כל החיתוכים נעשים עם re-encode דרך `filter_complex` (trim+concat).
  זה מבטיח חיתוך מדויק ברמת המילה — concat בלי re-encode היה "קופץ" ל-keyframe הקרוב
  ומאבד סנכרון.
* **דיוק הכתוביות:** אחרי הסרת הקטעים, כל מילה ממופה מהזמן המקורי לזמן הערוך לפי סכום
  משכי הקטעים שנשמרו לפניה — כך הכתוביות תמיד מסונכרנות לסרטון הסופי.
* **מבנה מודולרי:** `transcription.py` (שני מנועים, פלט זהה), `editing.py` (יישור +
  הסרת שתיקות), `subtitles.py` (SRT + RTL), `media.py` (FFmpeg), `cli.py` (הרכבה).

## מגבלות ידועות

* מצב ענן שולח את האודיו לספק הענן. אם התוכן רגיש — השתמש ב-`--engine local`.
* קבצי ענן מוגבלים בגודל (בד"כ ~25MB). הכלי מחלץ אודיו mono דחוס לפני העלאה, כך
  ש-5–10 דקות נכנסות בקלות; לקבצים ארוכים מאוד עדיף מצב מקומי.
* הצריבה (`--burn-subs`) דורשת גופן שמותקן במערכת ותומך בעברית.
