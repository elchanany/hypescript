# hypescript

כלי לעריכה אוטומטית של שיעורי וידאו בעברית: **חיתוך לפי סקריפט** (משאיר רק את
הטקסט שאתה נותן), **הסרת נשימות/שתיקות/מהססים**, ו**כתוביות עברית** מסונכרנות.

הפרויקט מחולק לשניים:

| תיקייה | מה זה | למי |
|---|---|---|
| [`web/`](web/) | **אפליקציית ווב** (Next.js) שרצה בדפדפן ונפרסת ב-Vercel. עיבוד הווידאו מקומי דרך `ffmpeg.wasm` — הווידאו לא עוזב את המחשב. | המסלול המרכזי |
| [`local/`](local/) | **כלי CLI + GUI** בפייתון (FFmpeg + faster-whisper/ענן). מהיר יותר לקבצים כבדים, ורץ 100% מקומי. | עיבוד כבד/לא-מקוון |

## איזה להריץ?

- **סתם לערוך שיעור בנוחות** → `web/` (ראה [web/README](web/README.md)). מזינים מפתח
  Groq בהגדרות, בוחרים וידאו + סקריפט, ומורידים תוצאה.
- **קבצים ארוכים/כבדים או בלי אינטרנט** → `local/` (ראה [local/README](local/README.md)).
  אותם אלגוריתמים בדיוק, עם רינדור FFmpeg מהיר במחשב.

שתי הגרסאות חולקות את אותה לוגיקת ליבה (יישור-סקריפט, הסרת שתיקות, SRT) — ב-`web`
היא כתובה ב-TypeScript, ב-`local` בפייתון.

## בהמשך

סוכן **AI** שיֵדע לחתוך ולערוך לבד (יחליט מה להשאיר) — ישתמש במפתח ה-OpenAI/AI
שמוגדר בהגדרות של אפליקציית הווב.
